# Чек-лист первого релиза PrintLantern

## До публикации

- [ ] Повторно проверить имя `printlantern` в GitHub.
- [ ] Выбрать и добавить лицензию проекта.
- [ ] Добавить владельца/контакты в `package.json`.
- [ ] Проверить очередь на физическом USB-принтере.
- [ ] Проверить очередь на сетевом принтере.
- [ ] Загрузить с телефона PDF, фотографию и DOCX.
- [ ] Проверить выбор страниц, копий, ориентации и позиционирование изображения.
- [ ] Подтвердить фактическую печать на выбранном принтере.
- [ ] Проверить прямую фоновую печать с включённым ползунком.
- [ ] Проверить «Печатать» и «Отклонить» с выключенным ползунком.
- [ ] Проверить QR-код в Wi-Fi сети без VPN.
- [ ] Проверить сценарий с несколькими сетевыми адаптерами.
- [ ] Проверить установщик на чистой Windows 10 и Windows 11.
- [ ] Настроить подпись Windows-приложения, если есть сертификат.

## Сборка

```powershell
npm ci
npm test
npm run check
npm run dist
```

В каталоге `release/` должны появиться установщик NSIS и portable `.exe`.

## Не включено в 0.1.0

- удалённое удаление или приостановка заданий;
- загрузка файлов с телефона на печать;
- авторизация PIN-кодом;
- поддержка системных очередей macOS и Linux;
- облачный доступ за пределами локальной сети.
