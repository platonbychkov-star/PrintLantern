# PrintLantern

PrintLantern — локальный сервис печати, в котором работа начинается с телефона:

```text
телефон → PrintLantern на компьютере → системный принтер Windows
```

Desktop-приложение запускает портал, показывает QR-код, историю файлов и состояние
принтеров, а также управляет локальной сетью. Загрузка и подготовка документов
выполняются в мобильном интерфейсе.

## Скачать

Готовые версии для Windows находятся на странице

## Возможности мобильного портала

- загрузка одного или нескольких файлов;
- вставка файла, изображения или текста из буфера обмена;
- форматы PDF, изображения, TXT/CSV/MD/JSON/XML/HTML, DOCX/RTF/ODT и другие;
- A4-предпросмотр в портретной и альбомной ориентации;
- выбор количества копий и диапазона страниц;
- масштабирование, вращение, смещение и перетаскивание изображения пальцем;
- команды «Вписать», «Заполнить» и «Центр»;
- выбор размера текста;
- очередь, история, прогресс и повторное открытие незавершённых заданий;
- отправка подготовленных страниц в системную печать Windows.

## Возможности desktop-приложения

- встроенный backend: пользователю не нужно устанавливать Python;
- QR-код для подключения телефона;
- включение и отключение доступа из локальной сети;
- выбор сетевого адреса и порта;
- выбор принтера Windows;
- переключатель прямой фоновой печати без открытия Paint;
- кнопки «Печатать» и «Отклонить» для ожидающих подтверждения заданий;
- отображение файлов из мобильного портала;
- использование истории прежнего локального Print Portal, если она найдена на
  этом компьютере.

Личные загрузки и история не входят в установщик и не публикуются.

## Разработка

Нужны Node.js 20+, Python 3.12+ и Windows 10/11.

```powershell
pnpm install
pnpm run backend
pnpm start
```

Проверки:

```powershell
pnpm test
pnpm run check
```

Сборка установщика и portable-версии:

```powershell
pnpm run dist
```

Готовые файлы появятся в `release/`.

## Подключение телефона

1. Запустите PrintLantern на компьютере, подключённом к принтеру.
2. Разрешите backend в брандмауэре Windows только для частных сетей.
3. Откройте раздел «Доступ с телефона».
4. Подключите телефон к той же Wi-Fi сети.
5. Отсканируйте QR-код.
6. Выберите файл, настройте A4-предпросмотр и нажмите «Отправить в принтер».

Если «Печатать сразу, без просмотра на ноутбуке» включено, задание напрямую
передаётся в системную очередь выбранного принтера через Windows GDI: Paint и
другие приложения не запускаются. Если переключатель выключен, задание ждёт
решения в desktop-приложении.
